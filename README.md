## Опыт работы

### .NET-разработчик — фриланс / коммерческая разработка
**2024 — настоящее время (2 года)**

Разработка веб-сайтов и веб-приложений на ASP.NET Core MVC для малого и среднего бизнеса: корпоративные сайты, каталоги, личные кабинеты, внутренние админ-панели и сервисы автоматизации.

**Чем занимался:**

- Проектировал и реализовывал бэкенд на ASP.NET Core MVC / .NET 6: контроллеры, бизнес-логика, слой доступа к данным на EF Core
- Проектировал схемы БД (MS SQL Server / PostgreSQL), писал и оптимизировал запросы, добавлял индексы — в одном из проектов ускорил выборку каталога с ~4 сек до ~300 мс за счёт пересмотра индексов и устранения N+1
- Реализовывал аутентификацию и авторизацию (ASP.NET Core Identity, JWT для API), разграничение прав доступа
- Разрабатывал REST API для интеграций: платёжные сервисы, CRM, почтовые рассылки, сторонние каталоги
- Писал unit-тесты для бизнес-логики (xUnit + Moq), выносил зависимости через DI, придерживался SOLID
- Вёл проекты полного цикла: сбор требований, оценка, декомпозиция, разработка, деплой на IIS/Linux, последующая поддержка
- Поддерживал и развивал существующие проекты на классическом ASP.NET MVC (.NET Framework): рефакторинг легаси-кода, исправление ошибок, добавление функциональности

**Результаты:**

- Сдал 10+ проектов под ключ, все — в согласованные сроки
- Несколько проектов перешли на долгосрочную поддержку и развитие
- Выстроил воспроизводимый процесс: шаблоны решений, чек-листы деплоя, собственный style guide
